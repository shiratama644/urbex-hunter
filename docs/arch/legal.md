# 法務・免責・データ帰属 — urbex-hunter

## 法務

- 本アプリは **非公式のファンプロジェクト**です。データの著作権は **全国心霊マップ（https://ghostmap.jp/）** に帰属します。取得したデータを商用で再配布しないでください。
- 全国心霊マップの **利用規約・robots.txt** を尊重し、スクレイピングは [`scraping.md`](./scraping.md) のポライトネス（同時接続6 / UA / 待機 / マージ）を守って行ってください。相手サーバーに負荷をかける行為は禁止します。
- 掲載地点の **アセット・画像・文章** を無断で他サービスへ転載しないでください。表示する際は `sourceUrl`（元記事URL）へのリンクを維持してください。
- 本プロジェクトのライセンスは **MIT**（ルート [`LICENSE`](../../LICENSE)）。依存ライブラリのライセンスは `package.json` の各パッケージに準じます。

## 免責（UI で必須表示）

以下の趣旨を `DisclaimerDialog`（初回訪問時の同意）およびフッター等で**必ず表示**し、文言を削除・弱体化しないでください。

- 本アプリの情報は正確性を保証しません。現地の状況は変化します。
- **私有地・立入禁止区域への侵入は禁止**です。法令とマナーを守ってください。
- **近隣住民・施設への配慮**を最優先してください。夜間の騒音・駐車・ライト等の迷惑行為をしないでください。
- 心霊スポットへの訪問は**各自の責任**で行ってください。事故・トラブルについて運営は責任を負いません。
- 危険な場所（崖・トンネル・廃墟・ダム等）では**安全を最優先**し、無理な侵入をしないでください。

訪問を推奨・煽る表現（例: 「肝試しに行こう」「今すぐ行け」等）を UI に追加しないでください。地図は「探索・閲覧」の位置づけに留めます。

## データ帰属の表示

- 地図上の各スポット詳細から `sourceUrl`（全国心霊マップの元記事）へ遷移できるリンクを維持してください。
- `README.md` / `docs/arch/product.md` / フッター等で「データ出典: 全国心霊マップ」であることを明示してください。
